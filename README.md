## Зачем это нужно

> Данные о развитии студента разбросаны по системам вуза, а подтвердить мягкие навыки работодателю и самому студенту нечем.

| 😕 Проблема | 💡 Что делает трекер | 🎁 Кто выигрывает |
|---|---|---|
| Портфолио собирается вручную и устаревает | Профиль наполняется из цифрового следа по мере активности | **Студент**: актуальный профиль и паспорт компетенций с QR |
| Диагностика разовая, динамики не видно | Баллы копятся непрерывно, уровни растут, виден прирост за 30 дней и прогноз следующего уровня | **Куратор**: видит, кому нужна поддержка и когда она может понадобиться, без ручных таблиц |
| Нет сводной картины по группам и направлениям | Теплокарта, таблица, статусы и лига групп на одной панели | **Вуз и Фонд**: аналитика по потокам и отчётность |
| Самооценка завышается, проверить нечем | Опрос сверяется с цифровым следом, расхождение подтверждается примером | **Все**: доверие к цифрам |
| Студенту непонятно, что делать дальше | Рекомендации с объяснением «почему это вам» и план на ближайшие недели | **Студент**: понятный следующий шаг |

## Как это работает

### От активности к уровню

```mermaid
flowchart LR
    A["📚 Источники данных<br/>Leader-ID · ЭИОС · Projects 2035<br/>кейсы · Добро.рф · онлайн-курсы"] --> B{"Согласие<br/>студента"}
    B -- "включён" --> C["Баллы записи<br/>× вес источника"]
    B -- "отключён" --> X["Источник<br/>исключён из расчёта"]
    C --> D["8 компетенций<br/>5 уровней"]
    Q["📝 Опрос самооценки"] -. "сверка" .-> D
    D --> E["👩‍🎓 Профиль студента"]
    D --> F["🧑‍🏫 Панель куратора"]
    D --> G["🪪 Паспорт с QR"]
    D --> H["🔮 Прогноз и рекомендации"]
    style A fill:#0f766e,stroke:#2dd4bf,color:#fff
    style B fill:#4c1d95,stroke:#a78bfa,color:#fff
    style X fill:#7f1d1d,stroke:#fb7185,color:#fff
    style D fill:#1e3a8a,stroke:#60a5fa,color:#fff
```

**Уровни** считаются по накопленным баллам компетенции:

| Уровень | 1 · Старт | 2 · Базовый | 3 · Уверенный | 4 · Продвинутый | 5 · Эксперт |
|---|:-:|:-:|:-:|:-:|:-:|
| Порог баллов | 0 | 80 | 200 | 380 | 600 |

Веса источников настраиваются на странице «Методика» (от 0 до 3), профили пересчитываются сразу.

### Статусы студентов

```mermaid
flowchart TD
    S(["Студент"]) --> Q1{"0 баллов<br/>за 30 дней?"}
    Q1 -- "да" --> I["⚪ Нет активности"]
    Q1 -- "нет" --> Q2{"2+ просадки<br/>или средний уровень < 1,8?"}
    Q2 -- "да" --> P["🟡 Нужна поддержка"]
    Q2 -- "нет" --> Q3{"≥ 200 баллов<br/>за 30 дней?"}
    Q3 -- "да" --> R["🟢 Растёт"]
    Q3 -- "нет" --> T["🔵 Стабильно"]
```

Просадка: больше 90 дней без активности в компетенции. В профиле студента статус дополняется прогнозом:
если до просадки осталось меньше месяца, показывается «поддержка через N дн.».

### Прогноз и рекомендации

- **Прогноз.** По темпу набора баллов за последние 12 недель (свежие недели весят больше) считается срок до следующего
  уровня по каждой компетенции и в целом, продолжение линии баллов на 3 месяца и надёжность оценки. У куратора то же по
  группам. Прогноз проверяется на истории: что он предсказал бы 4 недели назад против того, что случилось.
- **Рекомендации.** Для каждого мероприятия из каталога считается оценка: нужность (насколько слабая компетенция),
  польза (сколько баллов до следующего уровня), срок (когда стартует) и опыт других (у кого из участвовавших рос темп).
  Повторы компетенции и источника штрафуются. Рядом объяснение «почему это вам» и план по неделям.

## Возможности

| Раздел | Что делает |
|---|---|
| 🔐 **Вход и роли** | Логин и пароль или вход через Leader-ID; роли студент, куратор, администратор и демо-доступ только для чтения; заявки на регистрацию подтверждает администратор |
| 👥 **Студенты** | Четыре вида (направления, таблица, теплокарта, статусы), поиск, фильтр по направлению, легенда цветов |
| 🧑‍🎓 **Профиль** | Радар со сравнением с группой, уровни, прогноз и рекомендации, динамика с подсказкой по месяцам, карта активности, цели, записи |
| 🧑‍🏫 **Куратор** | Проверка примеров с возвратом решений, лига групп, матрица компетенций, прогноз по группам, импорт CSV |
| 📝 **Опрос** | 16 вопросов, сверка с цифровым следом, история прохождений, ответы сохраняются |
| 🔒 **Согласия** | Отключение источников, пересчёт уровней, выгрузка и удаление данных студента |
| 🔌 **Leader-ID** | Подключение из аккаунта, импорт завершённых участий, правила начисления баллов, обновление и отключение |
| 📐 **Методика** | Формулы и пороги, веса источников от 0 до 3, сброс |
| 🧭 **Каталог** | Активности по компетенциям с баллами, источником и датой |
| 🪪 **Паспорт** | QR-код и страница проверки подлинности |
| 📣 **Карточка для соцсетей** | Публичная ссылка на сильные стороны студента, включается самим студентом, картинка подстраивается под тему |
| 🧾 **Журнал** | Входы, просмотры, выгрузки, решения: периоды, фильтры, группировка по дням, выгрузка в CSV |
| 💼 **Окупаемость** | Калькулятор с тремя сценариями на 5 лет |
| 🎞️ **Презентация** | Слайды с живыми страницами, печать в PDF в цветах выбранной темы |
| ⚙️ **Настройки** | Тема, акцент, уровень анимаций; всё хранится в браузере |
| 📱 **Адаптивность** | Телефон, планшет, ПК; на устройствах без мыши отключены эффекты наведения |

Движение отключается настройкой «Анимации: выключены» или системной настройкой «уменьшить движение».

## Стек

| Слой | Технология | Почему |
|---|---|---|
| Интерфейс | Next.js 16 (App Router), React 19, TypeScript | серверные компоненты и действия без отдельного API |
| Стили | Tailwind CSS 4 и токены темы | светлая и тёмная темы и акценты из одних переменных |
| Данные | SQLite через встроенный `node:sqlite` | не нужны сервер БД и регистрации, всё разворачивается локально |
| Диаграммы | собственные SVG | печатаются в PDF в цветах темы |
| Движение | View Transitions и CSS | плавность без тяжёлых библиотек, три уровня в настройках |
| Паспорт | `qrcode` | QR на сервере, без внешних сервисов |
| Безопасность | scrypt для паролей, AES-256-GCM для токенов, лимиты попыток, роли на каждом действии | персональные данные студентов |
| Выкладка | сервер в России, https, отдельные ветки для проверки и боевого сайта | требования 152-ФЗ |

## Запуск

Исходный код закрыт: этот раздел для тех, кому автор предоставил доступ.

Нужен Node.js 22.5 или новее (модуль `node:sqlite`).

```bash
npm install
ADMIN_PASSWORD='ваш-пароль' npm run dev     # разработка, http://localhost:3000, вход admin
# или
npm run build && ADMIN_PASSWORD='ваш-пароль' npm start -- -p 3100
npm test                                    # пароли, лимиты попыток
```

База создаётся автоматически в `data/app.db`. Демо-данные генерируются при первом запуске и при каждом запуске
сдвигаются к сегодняшней дате, чтобы окна «30 дней», серии недель и просадки не устаревали.
Первый администратор создаётся из `ADMIN_PASSWORD`. Чтобы пересоздать данные, удалите файл `data/app.db`.

## Дорожная карта

1. **Пилот** на одном направлении с 1 курса: методика и набор компетенций согласуются с заказчиком и экспертами,
   уровни калибруются на реальных данных.
2. **Источники:** подключение ЭИОС и партнёрских платформ через официальные выгрузки или интеграции.
3. **Отчёт для декана** в один клик: участие, динамика и риски по группе за семестр.
4. **Расширение** на другие направления, колледжи и Медицинскую академию Югры.


## Ограничения

> [!WARNING]
> - Методика не валидирована на реальных данных: пороги и веса предстоит откалибровать на пилоте.
> - Из реальных источников подключён только Leader-ID, остальные данные демонстрационные или из CSV.
> - Расчёт окупаемости построен на оценочных допущениях и не является результатом измерений.
> - Прогноз и рекомендации объяснимы, но это оценка по истории, а не обещание.
