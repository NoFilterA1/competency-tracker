## Зачем это нужно

Компетенции студента сейчас не видны ни ему, ни вузу:

- **Портфолио собирается вручную.** Грамоты и справки теряются, устаревают, не сравниваются между собой.
- **Оценка разовая.** Диагностика проходит раз в несколько лет, рост между ними не виден.
- **Нет сводной картины.** Куратор не видит, у каких групп и по каким навыкам есть провалы.

Трекер решает это так: профиль наполняется по мере учёбы и активности, а самооценка студента сверяется с тем, что реально видно.

## Для кого

| Роль | Что получает |
|---|---|
| **Студент** | Профиль из восьми компетенций и пяти уровней, цели, рекомендации, паспорт с QR-проверкой, центр согласий: что участвует в профиле, а что нет |
| **Куратор** | Студенты по направлениям, теплокарта, статусы «растёт / стабильно / нужна поддержка / нет активности», журнал действий |
| **Администрация вуза** | Сводка по группам и направлениям, калькулятор окупаемости с настраиваемыми допущениями |
| **Жюри и заказчик** | Презентация с живыми экранами, скриншоты, доступ по отдельному логину только для просмотра |

## Возможности

- **Профиль студента:** радар компетенций с сравнением со средним по группе, динамика за 12 месяцев, карта активности за полгода, серия недель, значки.
- **Опрос самооценки:** 16 вопросов о поведении, а не о «правильных ответах». Результат сверяется с цифровым следом, расхождение подтверждается примером.
- **Согласия:** студент отключает любой источник данных, уровни пересчитываются сразу. Выгрузка своих данных в один клик.
- **Регистрация:** выбор группы из расписания университета, заявка подтверждается администратором.
- **Центр достижений:** рейтинг по приросту за 30 дней. В топе только те, кто сам включил показ. Фамилии сокращаются.
- **Журнал действий:** входы, просмотры, изменения, решения по примерам. С поиском и отменой решений куратора.
- **Защита:** роли на каждом действии, лимиты попыток входа, ежедневные копии базы.

## Дорожная карта

1. **Пилот** на одном направлении с 1 курса: методика и набор компетенций согласуются с заказчиком и экспертами.
2. **Источники:** подключение ЭИОС и партнёрских платформ через официальные выгрузки или интеграции.
3. **Расширение** на другие направления, колледжи и Медицинскую академию Югры.

## Технологии

Веб-приложение: серверный рендеринг, типизированный код, встроенная база данных без внешних сервисов. Вся инфраструктура может работать на одном сервере в России. Подробности реализации закрыты.
