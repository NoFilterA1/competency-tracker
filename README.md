# Трекер компетенций

Прототип системы трекинга мягких и профессиональных компетенций студентов на основе цифрового следа.
Учебный проект: профиль студента собирается из активности (учёба, мероприятия, проекты, кейсы, курсы),
уровни по 8 компетенциям растут по накопленным баллам.

> Все данные демонстрационные: студенты вымышленные, активности генерируются сид-скриптом при первом запуске.

## Возможности

- Профиль студента: радар компетенций (сравнение со средним по группе), уровни 1–5, динамика за 12 месяцев,
  карта активности, серия недель, достижения, алерт о просадке, лента записей и ручное добавление.
- Панель куратора: сводка, лига групп по приросту за 30 дней, матрица компетенций, таблица студентов
  с фильтром, импорт цифрового следа из CSV.
- Карточка профиля для публикации.
- Презентация (`/presentation`): слайды со встроенными живыми страницами прототипа.
- Светлая и тёмная темы, 8 акцентных цветов, адаптивная вёрстка (телефон и ПК).

## Стек

Next.js 16, React 19, TypeScript, Tailwind CSS 4, Recharts, SQLite (встроенный `node:sqlite`).
Внешних сервисов и регистраций не требуется.

## Запуск

Нужен Node.js 22.5 или новее (модуль `node:sqlite`).

```bash
npm install
npm run dev            # разработка, http://localhost:3000
# или
npm run build && npm start -- -p 3100
```

База создаётся автоматически в `data/app.db` с 24 демо-студентами. Чтобы пересоздать данные, удалите файл.

## Структура

```
app/                страницы и серверные действия (actions.ts)
  student/[id]/     профиль студента
  curator/          панель куратора
  share/[id]/       карточка для шеринга
  presentation/     презентация
components/         графики, карта активности, меню темы, слайды
lib/config.ts       компетенции, уровни, источники, шаблоны активностей
lib/db.ts           SQLite и сид демо-данных
lib/model.ts        расчёт уровней, серий, достижений, алертов
public/slides/      снимки страниц для печатной версии презентации
```

## CSV-импорт

Формат строк: `student_id,date,source,title,competency,points`.
Ключи компетенций: `communication, critical, teamwork, leadership, digital, project, selfdev, prof`.

## PDF презентации

Откройте `/presentation` и нажмите «Сохранить в PDF» (печать браузера, формат 1280×720, без полей).
Для светлой или тёмной версии выберите тему в меню «Тема» перед печатью.

## Ограничения

- Нет авторизации: запись (добавление активностей, импорт CSV) открыта всем, кто видит сайт.
- Автоматического сбора данных из ЭИОС и внешних платформ нет, только демо-данные и CSV.
